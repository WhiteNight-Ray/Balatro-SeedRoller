# Seed Roller 0.5.0 — 随机局精简版

基于 Lovely + Steamodded 的小丑牌（Balatro）Mod。

**[下载 v0.5.0 安装包](dist/SeedRoller-random-v0.5.0.zip)** · [完整中文说明](SeedRoller/README-中文.md)

解压安装包后，运行 `Install-SeedRoller.ps1`，或将 `SeedRoller` 文件夹复制到 `%APPDATA%\Balatro\Mods`。需要先安装 Lovely 和 Steamodded。

入口：**选项 → 种子筛选**。全鼠标操作，无快捷键、无常驻工具栏。

设置：目标小丑牌 A、可选的小丑牌 B、起始商店 N、结束商店 M，以及默认开启的「排除易腐」「排除租用」。点击目标牌名称打开列表，一次显示八张，可用鼠标滚轮上下浏览、点击名称选中，也可点击上下按钮一次翻八项。当前选择会高亮；B 列表第一项为「不选」。

## 筛选内容

- 包含第 N～M 次商店，含两个端点。编号按实际进店次数，从 1 开始。
- 每店的初始货架、刷新一次后的货架、两个位置出现的小丑包，都参与检测。
- 选一张目标时要求它出现；选两张时要求两张都出现，可在不同店、不同来源出现。A/B 不能设成同一张。
- 默认不将带易腐或租用属性的目标牌计为命中，适用于初始货架、刷新后货架及小丑包；两个开关独立，可关闭。其他非目标牌不受限制。同名牌先出现带禁用属性的副本、后出现合格副本时，记录后者的位置。
- 按当前赌注及牌本身的贴纸兼容性模拟属性，不修改牌的属性；不筛版本、价格、传说、标签、优惠券或其他卡包内容。
- N/M 支持 1～23。不跳盲时第 23 店是底注 8 大盲后的商店；击败 Boss 后先升底注再生成商店，例如第 3 店使用底注 2 的商店随机序列。

## 得到的是普通随机局

新版本直接调用游戏的普通开局接口，**不传入 seed，不写入或篡改 seeded 标记**。新局的内部随机种子由游戏自己的 `generate_starting_seed()` 生成。

不匹配就再次普通随机开局；匹配后保留当前对局，停在底注 1 初始选盲画面。不会拿命中的种子重新开启指定种子局。如果开始搜索时停在一个种子局开局，会先丢弃该局并正常随机重开，不会改标记冒充随机局。

这属于经过 Mod 筛选的普通随机对局。是否启用成就等其他功能仍由游戏及其他 Mod 的配置决定；本程序未验证这些功能。

## 操作

1. 退出游戏，安装本版到 `%APPDATA%\Balatro\Mods\SeedRoller`，重新启动。
2. 开一局，选好牌组和赌注，停在底注 1 尚未打牌、未跳盲的选盲画面，等待加载完成。
3. 点击 **选项 → 种子筛选**，点击 A/B 的牌名，在滚动列表中选择；设置 N、M 和属性排除开关，点击 **开始筛选**。
4. 程序自动重开普通随机局并预测目标。在菜单里查看检查次数和结果；打开菜单会暂停搜索，关闭后继续。
5. 命中会发出提示音、自动停止搜索并暂停游戏，直接弹出结果。每张目标分别显示商店编号、初始／刷新一次后货架或第几个小丑包，以及从左起第几格／第几张。点击「继续对局」关闭结果，继续原随机局；之后可在「选项 → 种子筛选 → 查看命中位置」再次查看本次游戏会话中的最近结果。
6. 如需中止：**选项 → 种子筛选 → 停止筛选**。原生加载锁生效期间需等菜单恢复可用。

默认最多检查 1,000 局，防止罕见条件无限运行。需要调整可修改 Steamodded 已保存的配置中的 `max_attempts`；界面不额外增加设置项。每次重开会等待游戏加载，比离线筛种算法慢。

## 必须遵循的预测路线

**筛选的是这条路线下“出现的牌”，不是所有操作下都能拿到的保证：**

1. 不跳盲，按小盲、大盲、Boss 的顺序进入商店。
2. 从第 1 店开始，每店先观察初始货架，再刷新恰好一次。
3. 刷新后，从左到右打开所有小丑包。只查看，跳过不选牌，再打开下一个。
4. 不购买货架商品或优惠券，不开其他类型卡包，不使用消耗牌。
5. **N 之前的店也要这样操作**，因为它们会推进随机序列；只是其中的牌不参与命中条件。

例：N=2、M=5，A=蓝图、B=头脑风暴。程序会从第 1 店开始模拟每店一次刷新和所有小丑包，但只有第 2～5 店出现的目标算匹配。两张可分布在不同商店，也可一张在货架、一张在小丑包。

买走第一张目标、从包里拿牌、跳过本该打开的小丑包、多刷新、买优惠券或用消耗牌，都可能改变后续结果。命中前后的这类操作不在本版模拟范围内。**本版不检查你是否有足够金币刷新／开包，也不保证能通关到目标商店，或能在拿走第一张后仍按预测拿到第二张。**

## 记录与兼容性

- 最近命中记录在 `%APPDATA%\Balatro\SeedRoller\random_match.lua`，包括内部随机种子、`seeded=false`、牌组、赌注、区间、完整预测货架与小丑包、目标位置。
- 内部随机种子用于记录；将其手动输入新局会开启种子局，因此请直接继续命中的当前随机局。
- 从 0.4.x 升级保留目标牌和商店区间，新增两个排除开关默认开启。从更早版本迁移时清空旧版标签、灵魂等配置。旧安装版本由安装器备份。
- 不修改 Brainstorm、Handy；请不要同时运行其他自动重开程序。检测到 Brainstorm 自动搜索、外部换局、种子局、加载超时等会停止。
- 预测面向原版内容 + Lovely + Steamodded；内容 Mod、新增消耗牌类型、第三方贴纸、覆盖原版贴纸 should_apply 规则和 object_weights 模式会被拒绝。无法识别所有第三方函数覆盖。
- 按当前解锁状态和初始牌组计算。游戏途中解锁新牌、其他 Mod 修改牌池、额外取得小丑牌等可能导致实际结果不同。
- 预测会恢复对局的 keyed RNG、底注、去重表、临时池和卡包权重，不创建虚拟牌。游戏原有抽样函数仍会推进 Lua 全局非 keyed RNG；不保证第三方钩子的全部状态隔离。
- 如果正常随机开局连续生成相同内部种子，程序停止并提示移动鼠标后重新搜索，不擅自注入指定种子。

- LuaJIT 语法检查与 32 项逻辑／接口测试通过，包括属性排除及开关、属性抽样边界、滚动范围、分数滚轮输入、点击选中和取消、退出后滚轮交还、配置升级，以及原有结果弹窗和随机局保留逻辑。
- 测试拦截任何对 `seeded` 标记的写入，并断言所有重开调用都不传种子、存档或挑战参数。
- 测试覆盖区间端点、前置商店推进、一次刷新、两种来源联合匹配、小丑包去重、跨底注、异常恢复、随机局保留、菜单暂停及精简界面。
- 使用本机游戏的实际生成函数及 Card:set_* 方法，在模拟渲染及简化牌池中对照 200 局 × 12 店，共 4,800 组货架、2,234 个小丑包，牌名、易腐、租用结果全部一致，覆盖不同赌注属性开关、牌的兼容性和全永恒修饰。
- 已在本机真实游戏中检查选项入口、居中布局、八行列表、鼠标滚轮浏览、当前项高亮、点击选中返回，以及旧目标牌／商店区间保留。
- 尚未完成真实游戏的完整操作路线与全部牌池验收。上述测试不是实际通关验证。

可复跑附带逻辑测试：

```powershell
python .\SeedRoller\tests\run_tests.py --lua-dll '你的Balatro目录\lua51.dll'
```

## 安装

手动复制整个 `SeedRoller` 文件夹到 `%APPDATA%\Balatro\Mods`，或在解压后的目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-SeedRoller.ps1
```

旧版会备份到 `%APPDATA%\Balatro\SeedRoller-backups`。卸载时退出游戏并移走 `Mods\SeedRoller` 文件夹。
